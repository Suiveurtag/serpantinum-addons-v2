# Serpantinum personal addons v2

Focused addons for the native Serpantinum Settings/Guide, independent of the retired v1 installer.

> **Personal project notice:** This is a personal project and may be unstable. Updates and ongoing maintenance are not guaranteed. Parts of it are developed with vibe coding, so review changes and test them in your own setup before relying on them.

- Addons: opt-in legacy calendar/clock and Mullvad DNS.
- Trackpad (in Addons): pointer-speed slider, native disable-while-typing protection, and a separate click guard during text entry. Uses the existing SettingsRow, Draggable and Toggle components.
- Mouse (in Addons): toggle adaptive pointer acceleration on or off for mice, persisted in a dedicated Hyprland Lua config fragment.
- Halloween night: one live switch for smoked burgundy surfaces, moving Settings mist, panel hearths, responsive webs, celestial engravings, energy around controls and repeating bat escapes on important hovers. Music gets an audio-reactive corona, system controls get conductive currents, widgets get effects matched to their face, and the network panel gets luminous transmissions along its existing orbital links. OFF unloads effects while preserving the selected theme. Halloween Night is a separate preset in Settings → Themes, with the supplied moon artwork. Directional panel/launcher arrivals, visible background crossings, modular bar charms, candlelit notifications and a finite eclipse intro extend the effects. See [design and validation](docs/halloween.md).
- Integrated settings panel (in Addons, off by default): `Super+Shift+P` opens Settings inside the shell, as before 2.3, preloaded so it opens instantly. It loads the same `GuidePopup` as the Settings app, so every current and future setting shows up in both. `Super+P` still opens the app. With the option off, `Super+Shift+P` opens the app too.
- Network: the same DNS switch, reflecting the active connection.
- Do Not Disturb (Keep Awake) has an optional **Codex mode** switch in Idle settings to also block system suspend and lid handling. It stays off unless enabled, and keeps the desktop session and network running for long tasks, downloads and AI workflows.
- Monitors: recovered v1 screen placement and snapping, resolution cards, rotation dial and refresh-rate slider, with native Guide scaling and an exact-coordinate alternative.
- Keybinds: recovered v1 keycaps, sliding edit control, expandable editor, shortcut recording, add/delete/save, and search. Choose multiple installed XKB keyboard layouts in order; Alt+Shift cycles between them. Layout changes apply immediately and persist. Existing Lua actions, options and generated workspace bindings are preserved.
- Cursor schemes: Guide → Addons → Mouse offers installed themes, archive imports, 16–128 px sizing, 31 customisable pointer roles, animated previews and click-point editing. Images, animated GIF/WebP, Windows `.cur`/`.ani` and Xcursor files can be assigned per role. Apply synchronises Hyprland, GTK 2/3/4, Qt/KDE, XWayland, D-Bus/systemd and Flatpak; imported images are retained locally. All cursor settings share one native group. Selecting a complete theme or restoring its default icons applies immediately; other edits use Apply. Each generated scheme has a content-specific theme name so applications can reload changed cursors. Toggle Normal select for every role without losing other role customisations. Reset individual roles, discard pending edits, or export a reusable theme archive to Downloads. Restart apps that cache cursors; applications drawing their own pointer retain control.
- Desktop drawing: `Super+Shift+D` opens a live annotation layer on the active screen. Draw with the left mouse button; choose freehand, ellipse, rectangle or stroke eraser in the themed bottom toolbar (P/C/R/E). Right-drag erases strokes; scroll changes pen width. Ctrl+Z undoes, Ctrl+Shift+Z redoes, Delete clears, and Escape or the shortcut closes and discards the session. Listed under Passive addons; search `addonDesktopDraw` in Keybinds to customize the shortcut.
- Desktop zoom: `Super+Shift+Z` toggles live desktop magnification around the pointer. The scroll wheel glides the zoom level without scrolling the app underneath; clicks pass through without closing zoom. Escape or the shortcut again restores the previous desktop zoom. The last selected level is remembered. Listed in Addons → Passive addons; search `addonDesktopZoom` in Keybinds to record another shortcut. Requires Hyprland with Lua configuration; session cursor settings are restored on exit or shell reload.
- Mouse spotlight: `Super+Shift+M` toggles a live spotlight around the pointer with an animated circle converging on entry and fading on exit. The rest of every screen dims Click or press Escape to dismiss; the closing click is consumed. Scroll to resize the circle. The Addons settings expose circle radius, background brightness with smooth cubic Bezier easing. Try it in Addons, or use its Shortcut button to open Keybinds and search `addonMouseSpotlight` to record a different combination. The installer preserves the customized binding. Cursor tracking runs only while the effect is visible and requires the active Hyprland session.
- Classic blur: the same addon surfaces follow native background blur and opacity, with a soft hover rim and clock/copy pulses. The picker blurs only the captured region behind its card; its samples and magnifier remain exact. No global theme setting is changed by installation.
- Liquid Glass: legacy clock/calendar, frozen-screen color picker, drawing toolbar, monitor controls, keybind editor, cursor settings and seasonal controls follow the native glass material. Hover sharpens the glass rim; the clock has a time-tinted lens that pulses with seconds, and copying a color sends a pulse through the picker. Disabling background blur restores the opaque fills. Sampled colors, cursor artwork and drawing ink stay exact.
- Color picker: `Super+Shift+C` or the pipette in the corner quick actions freezes the current screen, opens with a flowing theme-colored screen outline and a compact HEX preview. Click to expand the copy controls for HEX, RGB and HSL. A full-card confirmation animation closes the picker after a successful copy. Escape closes it; Enter selects the color, then copies HEX. Requires `grim` and `wl-copy`.
- Theme: Matugen, Vibrant and Vivid use the shell's original wallpaper theme tiles, colors, selection and animations.
- About stays last. Dragging Settings uses its title area; dragging an individual monitor affects the preview only, until Apply.

## Install

Run `python3 install.py` from the repository root, then `serpantinum reload`.

Compatibility checked with Serpantinum 2.3.0: addon pages use the standalone Settings window and its nested sidebar, alongside the native Welcome and Screenshot tabs. About stays last. Reinstallation restores the shared QML type registrations and the optional Wallpaper Engine hooks after an upstream update; wallpaper blur respects native snapshot mode.

Halloween's panel atmosphere follows the standalone Settings content area, including compact and right-to-left layouts. Opening Settings preserves the selected Vibrant/Vivid palette without regenerating wallpaper colors.

Requires the installed Serpantinum shell, Hyprland Lua configuration, NetworkManager, systemd-resolved, jq, matugen and Python with Pillow. Installation retains dated shell backups in `~/.local/share/serpantinum-addons-v2/backups/`. Reinstall after updating upstream; the patcher verifies known anchors before changing the shell.

Monitor changes apply to `~/.config/hypr/config/monitors.lua`. Keyboard edits update literal bindings in `~/.config/hypr/config/keybinds.lua`; generated workspace loops remain intact. The layout selector updates `~/.config/hypr/config/settings.lua`, preserving other XKB options and enabling `grp:alt_shift_toggle` only while multiple layouts are selected. Changes save backups and restore the previous file if reloading reports a configuration error. Conflicting external keybind edits require reloading the editor. The installer adds the color picker shortcut to the same Hyprland file and backs up its previous version.

Vibrant selects actual sampled wallpaper colors as accents. Vivid retains their hue while increasing saturation and brightness. Shell surfaces and text retain the upstream palette for readability; synthetic Matugen templates update application colors alongside the shell. Matugen mode follows the native generator. With Vibrant or Vivid active, Settings → Theme shows a Wallpaper accents editor: drag a point onto the wallpaper to choose where each accent is sampled, double-click a point (or right-click its chip) to restore it. Choices are saved per wallpaper in `~/.local/state/serpantinum/addons_v2_palette_overrides.json`.

## Validation

Trackpad changes apply immediately and persist in `~/.config/hypr/config/serpantinum_trackpad.lua`, loaded at the end of `hyprland.lua`. The three settings are kept in the adjacent JSON file. Only devices classified as touchpads by udev are configured; mice and TrackPoints are unaffected. Changes are backed up and rolled back if Hyprland reports a configuration error.

Mouse acceleration switches between Hyprland's `adaptive` and `flat` acceleration profiles. The selected profile persists in `~/.config/hypr/config/serpantinum_mouse_acceleration.lua` and applies after a Hyprland config reload.

The click guard requires Hyprland's Lua API (0.55+). It consumes left/right/middle trackpad clicks during text entry and for 600 ms after the last release, while leaving pointer motion available. Ctrl/Alt/Super shortcuts are excluded. Keyboard events are handled inside Hyprland without recording text. Existing compositor mouse shortcuts can still run. Native disable-while-typing depends on the touchpad's libinput support; combining both protections also covers physical clicks.

Run `python3 -m unittest discover -s tests -v` with Serpantinum installed. The tests cover native theme integration, sidebar ordering/idempotence, preservation of Lua binding actions/flags/generated loops, and external-edit conflicts.

The revised pages were also checked in the live shell. An actual pointer drag moved a monitor preview without moving Settings, and a keybind row expanded through real pointer input. These interaction checks did not save new monitor or keybind configurations.
